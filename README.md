# European Dental

The European Dental website in German (`/`), Italian (`/it/`) and English (`/en/`). It is static HTML,
CSS and JavaScript, generated by a Node script with no dependencies.

## Layout

- `site/` is the built site and the only folder that is served.
- `data/`, `i18n/` and `content/` hold the site data, the interface strings and the page copy.
- `assets/` holds the stylesheets, scripts, fonts and brand files, and `originals/` the source images.
- `_tools/` holds the generator and the checks.

Values marked `TODO` are not confirmed yet. They are filled in before launch and are never replaced
with example values.

## Build and check

```
node _tools/build.mjs              write site/
node _tools/build.mjs --check      fail if site/ is out of date
python _tools/verify.py
node _tools/check-placeholders.mjs
python _tools/contrast.py
```

The image and browser checks (`check-images`, `smoke`, `weigh`) need `npm ci` in `_tools/`, and the
browser checks need Microsoft Edge installed.

## Deploy

Cloudflare Workers, deployed with `npx wrangler deploy` from a machine logged into the hosting account:
check the account with `npx wrangler whoami` first, and run `node _tools/build.mjs --check` before deploying.
`wrangler.jsonc` serves `./site` only.

Until then, every push to `main` publishes a preview to https://agency-wo.github.io/european-dental/
(`.github/workflows/pages.yml`, through `_tools/pages-dist.mjs`).
